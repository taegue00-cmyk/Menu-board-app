# 브릿지 커피 디지털 메뉴판

테이블의 QR코드를 찍은 손님이 휴대폰으로 보는 디지털 메뉴판입니다.
파일은 `index.html` 하나뿐이고, 인터넷 브라우저에서 열면 바로 보입니다.

## 화면 구성

- **맨 위**: 가게 이름, 한 줄 소개, 위치
- **가운데**: 커피 / 논커피 / 디저트 버튼과 메뉴 카드 (이름, 가격, 한 줄 설명)
  - 사장님 추천 메뉴에는 작은 배지가 붙고 카드가 살짝 더 돋보입니다.
  - 품절 메뉴는 흐리게 보이고 '오늘 품절'이 표시됩니다.
- **맨 아래**: 영업 안내 (영업시간, 휴무일, 주차, 인스타, 좌석)
- **화면 아래에 항상 떠 있는 '전화 걸기' 버튼**

디자인은 반투명 유리 느낌(글래스모피즘)이며, 휴대폰 화면(가로 390px)에 맞춰져 있습니다.

## 열어 보기

1. `index.html` 파일을 더블클릭합니다.
2. 컴퓨터에서 휴대폰 화면처럼 보려면 브라우저에서 `F12` → 폰 모양 아이콘을 누릅니다.

## 내용 고치는 법

고치는 곳은 `index.html` **맨 위쪽 한 곳**입니다.
파일에서 `★★★ 사장님이 고치는 곳`을 검색(`Ctrl + F`)하면 찾을 수 있고, 자세한 설명이 한국어 주석으로 달려 있습니다.

| 하고 싶은 일 | 고치는 곳 |
|---|---|
| 가게 이름, 영업시간, 전화번호 바꾸기 | `var 가게` 안의 글자 |
| 가격, 메뉴 이름, 설명 바꾸기 | `var 메뉴` 안의 해당 메뉴 줄 |
| 메뉴 추가하기 | 같은 분류의 메뉴 한 줄을 복사해서 붙이고 글자만 바꾸기 |
| 메뉴 없애기 | 그 메뉴 줄을 지우기 (잠깐 숨기려면 줄 앞에 `//`) |
| 사장님 추천 메뉴 바꾸기 | `var 시그니처메뉴`의 이름 목록 |
| 추천 배지 글자 바꾸기 | `var 시그니처글자` |
| **품절 켜고 끄기** | 메뉴 줄 끝의 `품절: 0`을 `품절: 1`로 (다시 판매는 `0`으로) |

고친 뒤에는 저장(`Ctrl + S`)하고 브라우저에서 새로고침(`F5`)하면 바로 반영됩니다.

> 따옴표(`"`)와 줄 끝 쉼표(`,`)를 지우지 않도록 주의하세요.
> 화면이 하얗게 변하면 `Ctrl + Z`로 되돌리면 됩니다.

## 파일 구성

```
메뉴판/
├─ index.html   메뉴판 전체 (HTML, CSS, JavaScript가 한 파일에 들어 있음)
├─ CLAUDE.md    이 프로젝트의 작업 규칙
├─ README.md    지금 보고 있는 안내서
└─ 자료/         기획시트 등 참고 자료
```

## 사용한 기술

HTML, CSS, JavaScript만 사용했습니다. 별도 설치나 서버는 필요 없습니다.
글꼴은 고운 돋움(없으면 맑은 고딕)을 씁니다.
